# 異形見聞録

オリジナルA+ARTスロットのブラウザ試作版です。  
『大塚探偵事務所』の世界観をベースに、通常時・ボーナス・ART・継続ゾーンの遊技フローを検証するために制作しています。

## プレイ

- **公開ページ:** https://takaritu2011212-lang.github.io/igata-kenbunroku/
- **リポジトリ:** https://github.com/takaritu2011212-lang/igata-kenbunroku

ページを開くとそのまま遊技できます。外部ライブラリを使わず、HTML・CSS・JavaScriptで構成しています。

## 操作方法

1. **MAX BET** で投入します。
2. **レバー** でゲームを開始します。
3. 左・中・右の停止ボタンでリールを停止します。中央のパネルをタップすると、操作を順番に進められます。
4. ボーナス中はパネルをタップして消化します。
5. **データ初期化** で遊技データをリセットできます。

## 実装している主な要素

- 通常時、ART、継続ゾーン、特殊ART状態の管理
- BIGボーナス／レギュラーボーナス
- 小役抽選、払い出し、ボーナスとの重複当選
- ART中に成立したボーナスの待機処理
- ART中の回避ナビ、継続ゾーンの転落回避
- 総ゲーム数、ボーナス回数、ART回数、差枚数グラフ
- 開発用デバッグパネルによる状態変更・小役強制

## 現時点の仕様メモ

- 通常時は3枚掛け、ボーナス中は2枚掛けとして扱います。
- BIGは獲得枚数が242枚に到達した時点、REGは66枚に到達した時点で終了する設定です。
- ARTは基本30G単位で進行し、ART中に成立したボーナスはART消化後に処理する設計です。
- ART突入リプレイ、転落リプレイ、回避ナビを使って継続状態を管理します。
- 小役確率・重複当選率・差枚数に関する値は、開発中の仕様に基づくものです。
